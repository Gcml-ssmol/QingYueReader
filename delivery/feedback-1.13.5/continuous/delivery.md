# Android 1.13.5 continuous notes handoff

Scope: isolated copy `work/feedback-1.13.5/continuous/QingYuePDF`, based on read-only `outputs/1.13.4/QingYuePDF`. This task owns NoteCanvasView.java, new NotePageLayout.java, and tests/note-continuous/NoteContinuousTest.java and its run.ps1 entry point. NoteDocument.java and the v3 wire format are byte-for-byte unchanged. No NoteActivity.java, shared main project, regression script, version, signing key, or release APK was changed.

Finite paper defaults to a unified vertical viewport when `horizontalPages=false`. Pages retain their local item coordinates and are drawn only when they intersect the viewport. The paper gap rejects a new pen stroke. Touching a visible page for editing selects that page at contact; it remains the stroke/eraser owner through the gesture even if the viewport centre lies elsewhere. Hand and touch pan continuously across page boundaries without snap or edge release page turn. Existing infinite canvas and horizontal page-turn paths remain. Images, text, and source excerpts use the current page's local centre. New pages keep the current absolute zoom and horizontal anchor; cancelled gestures settle the page index. Far-page ink cache checks use a page-local viewport centre. Width-based fit makes finite paper fill the available reading width; resizing the sidebar keeps absolute zoom and viewport anchor.

API for NoteActivity owner: existing `setHorizontalPages`, `selectPage`, `addPage`, `insertPage`, `movePage`, and `fit` remain. `visiblePage()` returns the viewport-centre 0-based page index. `Host.viewportPageChanged(int)` fires only when continuous page selection changes, for lightweight page number/thumbnail/undo UI. `Host.viewportSettled()` fires once after a page-changing gesture finishes, for library index persistence. Explicit page operations still call `Host.pageChanged()`. These new callbacks have default no-op implementations; integrate them in NoteActivity for live UI. Explicit `selectPage` now positions the target page near its top while retaining current absolute zoom. The saved v3 centre Y remains page local, including for old documents. Undo remains scoped to the active page and follows the existing baseline rule that switching pages clears its in-memory undo stack.
