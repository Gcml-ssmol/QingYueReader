# Android 1.14.0 note editor handoff

Scope: independent `work/feedback-1.14.0/editor/QingYuePDF`, copied from read-only `outputs/1.13.5/QingYuePDF`. Only NoteDocument, NoteCanvasView, NoteStore, ZoomLimits, new NoteEditorOps and `tests/note-editor` are changed. NoteActivity, NoteDialogs, MainActivity, page sidebar, version and signing material remain with the UI/integration owner.

The canvas now supports rectangle/freehand lasso across handwriting, geometry, text and image objects. Vector selection uses actual strokes and shape outlines (including ink width), so an empty corner inside a large bounding box does not select a distant stroke. It previews grouped move and uniform scale, and exposes copy/cut/paste/delete, recolor, explicit scaling, and drawing-order top/bottom actions. Every committed group action uses one model history entry. Recolor preserves each item's alpha, including highlighter ink. A whole-stroke eraser joins the existing partial vector eraser. Marker-only filtering is deliberately unavailable because v3 does not store a reliable brush kind and pencil ink can also be translucent.

Page actions duplicate, clear and delete the current page. Duplicates receive new global item IDs and retain same-note image filenames; `NoteStore.imageExists` verifies image ownership before clipboard paste. Clear is undoable; deletion keeps at least one page. The temporary clipboard belongs to one NoteCanvasView/note and may paste across pages of that same note. It is intentionally not shared across notes or persisted.

The v3 wire version and Item representation are unchanged. Existing v1/v2/v3 reading, autosave and opaque backup remain. PDF/PNG export and previews still use the same item types. Arbitrary image/text rotation, per-page backgrounds, true layers, persistent brush metadata, recording, AI and cloud account features are outside this v3-safe editor change.

Public Canvas API: `setTool("lasso",...)`; `setLassoFreeform(boolean)`; `setLassoFilter(int)` with `LASSO_HANDWRITING`, `LASSO_GRAPHICS`, `LASSO_TEXT`, `LASSO_IMAGE`, `LASSO_ALL`; `selectionCount()`, `hasClipboard()`, `copySelection()`, `cutSelection()`, `pasteSelection()`, `deleteSelection()`, `recolorSelection(int)`, `scaleSelection(float)`, `bringSelectionForward()` (to top), `sendSelectionBackward()` (to bottom), `setWholeStrokeEraser(boolean)`, `duplicatePage()`, `clearPage()`, `deletePage()`, `resetOrigin()`, `setReadOnly(boolean)`. Read-only mode blocks pen/eraser edits, explicit write calls and the horizontal last-page pull-to-add gesture while retaining navigation. Existing `setZoomPercent(int)` supports 50–1000 only for infinite canvas; finite paper stays 50–300. The absolute zoom stored in v3 never exceeds 32. UI should call `setZoomPercent(100)` for 100% and `fit()` for fit. Page creation/deletion uses existing Host page callbacks.

Verification: Android 35 SDK `javac --release 8` of all 108 production Java files; `tests/note-editor/run.ps1 -BuildDirectory <external directory>` (including actual outline selection against empty bounding-box corners, batch undo, whole/partial eraser, alpha, duplicate/clear/delete, v3 reopen, 10x zoom, actual NoteStore image ownership and export bounds); existing note-store and basic-note-export suites. These are desktop tests and compilation, not device testing. Independent production Canvas interaction QA is pending final result.
