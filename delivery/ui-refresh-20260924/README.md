## 总管后续验收

源码和可复核增量交给总管统一审查、定版、签名与发布。Windows 上的 Java/Chromium 测试不代表 Android、iPad 或 iPhone 真机通过；尚未运行 Xcode、生成 IPA 或执行设备安装。建议设备验收覆盖两种风格、浅深/跟随系统、窄屏/大字体、阅读批注、键盘遮挡与原生文件分享。

此轮工作区原本包含大量其他任务未提交修改。因此交付使用单独审查仓库记录“本次请求开始前的准确文件快照 → 本次最终 UI”的增量，避免将原有改动归入 UI 任务。`changed-files.json` 提供逐文件前后 SHA-256；`ui-refresh.patch` 和 `ui-refresh-review.bundle` 用于复核。独立仓库的提交不可直接当作主项目分支执行 cherry-pick；共享工作区已是完成状态，无需重复应用补丁。
