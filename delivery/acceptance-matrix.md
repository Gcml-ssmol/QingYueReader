## 审批门槛

1. 每个模块提交可固定审查的 Git commit、变更和验证说明；根窗口复核实际代码及必要回归。
2. 阻止数据丢失的预审问题必须修复，不能以模块测试通过代替。
3. 跨模块导出、恢复、来源跳转、录音和搜索必须有真实入口及实调用；不能以按钮或接口存在代替功能完成。
4. 最终集成后统一 Manifest、主题、版本、依赖和构建，再复核签名及交付包。
5. 用户本轮暂不连接 Android 设备。触控、手掌、录音、OCR 原生执行、旋转、多窗口、低内存及旧版覆盖安装的设备结果一律写为未验证，不能声称通过。
