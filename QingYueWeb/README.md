# 晴阅网页版 0.2.1 · iPad 优先

独立的 Safari / 主屏幕网页应用，优先适配 iPad 横屏、竖屏，兼容 iPhone 窄屏。默认界面现采用受 Codex 启发的中性色、侧栏与轻量过渡，外观设置仍可切回经典原版。目标为 iPadOS / iOS 18 及以上的 Safari；这是网页体验版，不是原生安装包。Android 主线仍在 QingYuePDF。

## iPhone 与 iPad 互通范围

两种设备共用同一个网页程序与 `.qyweb` 备份格式，资料保存在各自设备，不自动同步。可以在设备 A 导出完整备份，通过系统“文件”、隔空投送等转移文件，再在设备 B 恢复。恢复会创建副本目录而非双向合并，反复往返可能产生重复资料；建议选一台设备作为主要编辑设备。GitHub 源码上传和网站发布不提供资料同步。

## 0.2 平板适配

- 视窗宽度达到 760 CSS 像素时，资料库常驻左侧嵌套目录树；进入文件夹仍显示直接子目录与资料。iPad 分屏较窄时自动切回紧凑布局。
- 平板阅读器左侧显示附近页面预览，包含本机文字和笔迹，支持点选跳页、前后移动预览范围；空白笔记可以直接“新页”。左上角按钮可收合页面栏。
- 横屏宽度足够时工具与样式同行；竖屏分行，保留较大的触控按钮。阅读列随侧栏和屏幕尺寸变化重新绘制，布局变化时取消尚未完成的触摸操作，避免坐标错位。
- 保留 0.1 的存储、导出及备份格式，不另建 iPad 数据库，不增加云同步。

## 使用

用 Safari 打开交付的 HTTPS 地址。当前站点已公开，不要求 ChatGPT 账号。点击 Safari 分享 → 添加到主屏幕；出现“作为网页 App 打开”时开启。首次联网打开，等待“离线资源已准备”。

0.2.1 修复已缓存页面仍等待网络的问题：再次打开时优先使用已安装的页面。离线资源安装失败时会明确提示，设置中可以重试。首次访问的托管拦截仍需入口侧解决；独立部署与资料迁移见 [国内访问与迁移](deployment/国内访问与迁移.md)。

PDF 与批注保存在当前网站、当前设备的 IndexedDB，阅读文件不上传。Safari 与主屏幕应用是否共享既有网站数据取决于系统环境；首次体验后请在准备长期使用的入口导入资料。请定期通过右下角齿轮导出 .qyweb 备份；清理网站数据、无痕浏览或系统清理可能移除本机资料。

## 已实现

- 根目录显示文件夹与未分类资料；嵌套、重命名、移动、回收站和保留副本恢复。
- PDF 导入与单页阅读、页码跳转、原页缩略图、手动书签、50%–300% 缩放。
- 画笔、荧光笔、局部橡皮、撤销；工具独立保存样式。
- 中文和英文多行文本框、TXT 文件读取；文字可以编辑、移动或删除。
- A4 空白笔记，阅读设置中“新建一页”。
- 带批注 PDF 导出，保留原页面和原文字层，新增文字可搜索；原文件不改写。
- .qyweb 完整备份及校验后恢复副本；离线资源缓存；右下角齿轮设置。

## 首版边界

单 PDF 最多 40 MB、3000 页，空白笔记最多 200 页，整库备份最多 100 MB / 1000 份资料。TXT 最多 64 KB、8192 字符，无自动换行；缺失字形会阻止 PDF 导出并提示。较大文件仍受 iPhone 可用内存限制。

不含 Android 的 OCR、EPUB / Word 原件转换、全库正文搜索、压感笔、套索、笔记页面排序/滑动增页、云同步和 Android .qyb 备份导入。可先在 Android 导出 PDF，再到这里导入。平板左侧预览包含批注；阅读菜单里的缩略图仍只显示原 PDF。

## 源码和部署

纯静态文件，无 npm 安装或打包要求；所有运行依赖随 dist 一同提供，不依赖第三方 CDN。修改 dist 后运行 `node prepare-offline.mjs` 更新离线缓存。部署整个 dist 到 HTTPS 静态站点；不要以 file:// 直接双击打开。开发时可用 `python -m http.server 5180 --bind 127.0.0.1 --directory dist`，访问 localhost。HTTP 局域网地址无法完整启用存储摘要与离线缓存。

`.openai/hosting.json` 记录 Sites 项目。发布包包括该文件和 dist。源码不含令牌、私钥或用户文档。第三方许可见 dist/licenses 与 THIRD-PARTY.md。

## 验证

在 Windows 的隔离 Edge / Chromium 手机视窗 390×844 中完成：目录嵌套、文本笔记、增页、重开持久化、备份恢复、离线重新加载；没有浏览器 pageerror。真实 PDF 导出测试覆盖四种旋转、透明荧光笔接点、单点笔迹、中文文本提取及原件不变；中文 PDF 用 Poppler 渲染并检查可见文字。额外检查局部橡皮切分、缩放上下限、拒绝旧窗口覆盖、损坏备份不写入、文件夹循环拒绝。

0.2 另用 1194×834 和 834×1194 平板视窗验证资料树、阅读器横竖布局、无整页横向溢出、侧栏收放后的画布重绘、含批注预览、选页/增页，以及独立浏览器存储之间 iPad → iPhone → iPad 的备份互转。0.1 的手机完整流程在 0.2 再次通过。

测试脚本在 tests，需自行安装 Playwright 并提供 Chromium / Edge。运行 `node tests/tablet.cjs` 或 `node tests/smoke.cjs`；默认开发地址为 http://127.0.0.1:5180。尚未连接 iPad 或 iPhone，也没有 WebKit 测试运行时；Safari 安装、系统分享、真实 Apple Pencil / 手势和内存表现未作实机验证。可选 WebMCP 工具按能力检测注册，当前浏览器不支持，未验证实际调用。
