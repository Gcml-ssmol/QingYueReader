# 晴阅 · 1.7.0

中文 Android 本地阅读、手写批注与笔记 App。采用原生界面，使用系统 PdfRenderer 显示 PDF，PDFBox Android 在本机提取文字用于搜索；不申请网络权限，不上传文档。

## 本次新增

- 文档库新增「新建笔记」，与 PDF、Word、TXT 文档统一管理，支持重命名与删除。
- 底纹提供全空、横线、网格；每种均可搭配 A3、A4、A5、B4、B5、Letter 六种固定尺寸，或宽度、长度均可延伸的无限画布，共21种组合。
- 固定纸张使用纵向尺寸，B4/B5 使用 ISO 标准。无限画布可向上下左右平移，以矢量坐标保存内容，不创建无限大的位图。
- 笔记支持画笔、荧光笔、整笔橡皮、直线、圆形、矩形和箭头。选择图形工具后按住拖动，松手完成；长按或再次点击工具调节颜色与粗细。
- 点击图片图标插入图片，自动进入选择模式。拖动图片移动位置，拖动四个角等比例缩放；垃圾桶删除选中的图片。之后可点击选择工具，再次选中已插入的图片。
- 图片移动、缩放、删除与笔迹编辑均支持撤销、重做。默认仅手写笔绘制，手指平移；选择模式下可用手指调整图片。双指捏合缩放，双指轻点撤销，可在笔记设置关闭。
- 笔记自动保存内容、图片位置、画布缩放与浏览位置；离开编辑器时提交最新状态。最多保留30步当前编辑会话的撤销历史，重新打开后历史重置。
- 沿用奶油白、杏橙色界面。工具行居左，窄屏可横向滑动；标题栏可收起，仅保留工具行。

## Word 与文本导入

「导入文档」支持 PDF、DOC、DOCX、TXT，也可从系统其他应用使用打开或分享入口导入这些格式。

PDF 保留原页面。DOC、DOCX、TXT 在本机提取文字后，重新排版为 A4 页面，随后可使用已有阅读、搜索、手写批注功能。**Word 的复杂版式、内嵌图片、表格样式、页眉页脚不会完整保留，也不提供 Word 原格式编辑或导出。** 需要保留原样的文档请先导出为 PDF。

DOC 使用 Apache POI HWPF 解析真实 Word 二进制文件，兼容常见旧版 Word；DOCX 读取正文中的段落和表格文字。TXT 支持 UTF-8、带 BOM 的 UTF-16，以及常见中文 GB18030 文本。

为控制移动设备内存，PDF 最大200MB；DOC 最大32MB；TXT 最大8MB；DOCX 解压后的正文 XML 最大16MB。Word/文本提取结果最多200万字符、重新排版最多400页，超过限制会提示拆分或先转 PDF。纯图片 Word 没有可提取正文时会提示转换为 PDF；本版不包含 OCR。

## 笔记图片与本地数据

支持 JPG、PNG 及系统能解码的图片；单张导入文件最多32MB，长边采样到不超过2048像素，保存本地副本并修正常见照片方向。原始图片不会被修改。无限模式指画布没有预设边界，实际笔迹数量仍受设备存储、内存和单笔记容量限制。

删除笔记会删除其中的笔迹、图形和本地图片，并且无法撤销。卸载应用或清除应用数据也会删除所有本地笔记；当前版本不提供笔记导出或云同步。

## 保留的界面与阅读功能

- 更多菜单、阅读设置、跳页、清空批注确认、操作说明、导入进度与错误提示，全部改为与文档管理一致的奶油白、杏橙色卡片。
- 菜单使用图标、主副标题与独立操作卡；阅读模式使用可点选的互斥卡片，双指撤销开关独立分组。
- 搜索入口固定在工具行最右侧、下拉按钮左边；标题栏收起后仍可使用。标题栏与更多菜单中不再重复放置搜索。
- 搜索面板采用图标标题、描边输入框和独立结果卡片；每条显示页码、命中次数、片段与跳转提示。
- 保留画笔的长按/再次点击浮层，并统一标题图标样式；弹窗适配横屏、小窗口、输入法与大字体。

## 阅读与搜索功能

- 阅读器标题栏在滑动阅读时自动收起，保留居左的紧凑工具行；最右侧箭头可手动展开或收起。
- 撤销、重做与画笔放在同一行。手机宽度不足时可横向滚动工具行，最右侧展开按钮固定可见。
- 默认开启双指轻点撤销，可在「更多 → 阅读设置」关闭；设置自动保存。
- 阅读设置可选择「上下连续滚动」或「左右滑动翻页」，两种模式互斥。
- 左右模式按单页宽高适配，支持跟手拖动、平滑过渡和边界回弹；相邻页按钮也使用动画。远距离跳页直接定位。
- PDF 内容搜索显示命中页码、次数和片段，点击结果跳转。支持中文、全角文字、英文忽略大小写和跨行匹配。
- 文档管理、重命名、移除确认均重绘为紧凑卡片，保留奶油白、杏橙色视觉。移除操作明确区分 App 副本与原始 PDF。

## 阅读与批注

导入 PDF 后点击笔形或荧光笔图标，用手写笔绘制。默认只接受系统识别为 STYLUS 或 ERASER 的笔输入；普通电容笔若被识别为手指，在此模式下不能绘制。点击带勾的笔图标可允许手指绘制。

长按画笔、荧光笔或橡皮，或再次点击已选中的工具，打开图标附近的颜色与粗细面板。支持18个实心圆常用色、6个最近颜色、HSV光谱、HEX色号、页面吸管取色，以及动态圆点与线段粗细预览。三种工具分别保存大小。

橡皮为整笔擦除，触及一条笔迹就移除整条。撤销与重做针对当前页，包含笔画、擦除、清空等编辑；每个缓存页最多保存30次撤销历史，离开文档或页面移出缓存后历史重置。双指轻点使用相同的撤销功能。

双指轻点需要两指近同时落下、短按后抬起，且没有明显移动；双指拖动和捏合仍用于平移、缩放。手写笔书写时忽略同时接触的手掌。

上下模式提供平滑连续浏览与自然减速，左右滑动不切页。左右模式每次一页，上下拖动不跨页；放大后可平移当前页，到达水平边缘后再次向外滑动可切页。底部页码可直接跳页，更多菜单可恢复默认页面适配。

文档库保存导入的本地副本，支持名称搜索、重命名、移除与重复内容识别。自动保存阅读页码与各页批注；顶部状态显示保存情况，失败时可展开标题栏后点击状态重试。

## PDF 内容搜索

点击工具行最右侧、下拉按钮左边的放大镜，输入关键词后点击搜索图标或键盘搜索键。标题栏收起时，搜索入口仍固定可见。搜索过程在后台进行，可随时停止；结果陆续出现，点击任一结果跳转到对应页。改变关键词会取消旧查询并清空旧结果，关闭面板也会停止搜索。

每次最多显示200个命中页面，每页显示匹配次数和一个上下文片段；达到上限会提示缩小关键词范围。搜索定位到页面，目前不在 PDF 页面内绘制命中高亮。

只搜索可提取的 PDF 文字层。纯图片扫描件、文字已转轮廓或缺少有效字符映射的内容可能无法搜索；本版未加入 OCR。App 手写批注也不作为文字搜索。部分失败页面会提示，已找到的结果仍可使用。

## 安装与数据

安装 `qingyue-pdf-1.7.0.apk`。沿用此前版本包名 `cn.qingyue.pdf` 与同一本地签名，直接覆盖安装，不要先卸载旧版，以保留文档、批注与阅读进度。

支持 Android 6.0（API23）及以上。每份 PDF 最大200MB；不支持密码保护 PDF。批注只保存在 App 内，目前不导出带批注的 PDF。卸载、清除 App 数据或移除文档会删除相应本地数据，请保留原始 PDF。

## 构建

需要 JDK17、Android SDK Platform35 和 Build Tools35.0.0。第三方二进制、校验值、许可证随源码附在 third-party，无需额外联网下载。

```powershell
.\build-apk.ps1 -SdkRoot 'C:\path\to\android-sdk' -BuildDirectory 'C:\path\to\existing-build'
```

覆盖安装必须沿用原构建目录中的 `local-test.keystore`。本次交付继续使用此前版本的本地测试签名，不是应用商店发布凭据。项目也包含 Android Studio / Gradle 配置，未附 Gradle Wrapper。

构建脚本验证依赖SHA256，编译资源、Java和所有DEX，使用 D8/L8 及随附的 desugar_jdk_libs_nio 回移 Word 解析依赖所需的 Java API，使用正斜杠路径打包PDF字体/CMap资源与许可证，然后对齐、签名、验证APK。第三方组件及来源见 third-party/README.md。POI 未使用的桌面绘图/OSGi 类会出现 D8 缺失类型警告；正文提取使用 InputStream 路径，不调用桌面绘图转换器。
