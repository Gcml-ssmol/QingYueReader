## 1.14.0 无限草稿与编辑工具

当前版本为 1.14.0（versionCode 24）。首次创建默认无限草稿，同时保留上下连续的分页笔记；创建面板记住成功创建时的模式、底纹和纸张尺寸。笔记进入、返回以及操作面板使用短暂过渡，系统关闭动画时直接切换，不对书写画布添加动画。

## 1.13.4 插页与绘制优化

当前版本为 1.13.4（versionCode 22）。PDF 与笔记的页面栏提供「插入空白页」，可在当前页之前或之后插入，默认之后并选中新页。例如原 PDF 第 12 页后插入，新空白页为第 13 页，原第 13 页及后续页顺延。

- PDF 原位修改库内工作文件，文档编号、导入身份和保留的来源附件不变。迁移原页笔迹、清空恢复记录、书签、文字批注、OCR 修订和库内笔记来源链接；原 PDF 的内部目录、链接及页标签保持原目标，新页继承相邻页尺寸与旋转，可书写、重开和备份。
- 插页前排空保存队列；其他窗口仍在编辑目标 PDF 或引用笔记时会提示先关闭。事务保留原件并在下次启动后台恢复；恢复未完成时不开放编辑。加密、限制修改及已签名 PDF 暂不支持插页；损坏的侧车或笔记会保守阻止操作。应用外已复制的旧页号来源链接不会自动更新。
- 页面栏按钮固定在画笔工具条最左侧，使用矩形分栏图标；PDF 与笔记一致，窄屏也可访问插页。缩略图行复用并检查异步请求身份，减少滚动时的重复创建和串图。
- 笔迹几何采用有界缓存，PDF 高清瓦片优先绘制可见区域；仍保持原有笔迹顺序、颜色和荧光笔透明度。桌面计数验证了重复构造减少，实际设备帧率与内存表现尚待测量。

本节描述三组交付的实现范围，最终整包验证见 `delivery/1.13.4-review.md` 和安装包旁的验证说明。尚未完成真机验收，尤其需核对大 PDF 插页、持续书写、侧栏布局和等待期间旋转恢复。以下历史章节保留各版原记录。

## 1.13.3 反馈修复

6. PDF 与笔记工具栏保留全宽，页面栏和阅读区位于工具栏下方；超宽工具可横向滚动，笔记侧栏提供可见页预览、选页、调序和新增。
7. 书签行按实际页码跳转，编辑/删除按稳定 ID 操作；新增时可命名，已有书签可重命名，并保留 ID、目标页和创建时间。导航重载使用加载 token 与修订检查，保留已暂存的修改。
8. 仅有最近删除项引用的空文件夹允许删除；回收站资料及原文件保留，恢复位置改为父级，删除顶层文件夹后恢复到未分类。仍有活跃资料或子文件夹时继续阻止删除。

## 1.9.3 日志定位修复

用户提供的 1.9.2 故障记录显示 OPPO OPD2506、Android 16 / API 36 在 InkStore.annotatedPages 第 77 行抛出 NoSuchMethodError。核对实际 DEX，发现程序调用 keySet():KeySetView，但随包的 Java 兼容库仅提供 keySet():Set。已把批注缓存的调用改为 ConcurrentMap 接口，在保持线程安全的同时使用一致的方法签名；导航读取和删除清理的三处调用全部修正。

构建现包含真实 DEX 链接检查：旧 1.9.2 产物会被拒绝，新包必须同时满足三处调用返回 Set 与兼容库实现匹配。导航读取批注的失败也会提示并保留其他栏目。源码、JVM 和构建验证不能替代设备运行；请覆盖安装后复测导航及删除。

## 使用

首页「导入」添加文件；文档右侧菜单可收藏、整理、重命名、移入最近删除。右下角齿轮「设置」内有备份、恢复、最近删除、扫描修复和外观设置。恢复备份前会保留本地安全副本。

PDF 顶部搜索按钮可查找文字；阅读器菜单提供导航、选字、高级批注工具、摘录到笔记、导出与恢复清空。摘录插入后，在笔记顶部点击「来源」选择条目即可返回原文；长摘录建议使用无限画布。导出 PDF 可填写例如 `3-12` 的范围；当前页 PNG 最长边不超过 4096 像素，且不超过 600 万像素，并根据可用堆限制降低尺寸。

「新建笔记」支持多页、底纹、固定纸张或无限画布、书写、图形、图片、撤销与重做。左侧页面栏选页和调序，右上角设置可增页。标题栏导出可选择全部页面 PDF 或当前页 PNG。无限画布逐页按内容边界导出，空白页按 A4；PNG 最长边 4096 像素，不超过 1600 万像素。导出不包含屏幕缩放标签。

## 使用边界

- 双栏、录音、复习卡片与 WebDAV 同步未纳入本包。扫描件保存 OCR 后可用全库搜索；要在 PDF 页内直接搜索、选字，需导出可搜索 PDF 后重新导入副本。
- EPUB/Word/文本按正文重新排版为 PDF，复杂版式、图片与表格样式不会完整保留；需要原样阅读时请先转换为 PDF。EPUB 文件上限 64 MB、解压条目合计 48 MB、单条目 8 MB、正文 200 万字符；重新排版后的文档最多 400 页，超限会提示而不截断导入。为保持离线导入，不载入外部资源或执行脚本。
- `.qyb` 用于恢复可编辑资料。PDF/PNG 是阅读副本，不能替代完整备份；应用内书签保留在 `.qyb`，不新增为导出 PDF 的目录项。备份未加密，请自行选择保存位置。
- PDF 指定页码导出会去掉原目录，原文内部跳转、页标签或表单可能仍引用原页码，重要文件请核对副本。导出失败或取消后，系统保存位置可能留有不完整文件。
- PDF 导出途中退出阅读器、旋转或系统结束进程时需重新导出；笔记保存位置选择器支持普通旋转，进程被结束后需重新发起。导出时不要删除对应资料或图片。
- 单页笔记导出范围任一方向超过 14400 pt，或坐标超过 100 万 pt 时会拒绝导出。卸载或清除应用数据会删除本机资料，请先导出 `.qyb`。
- 版本通过源码审查、JVM 回归与 APK 构建校验；没有连接 Android 设备，尚未验证实际安装、布局、触控/压感、文件选择器及导出显示。删除最后一份的原始闪退没有日志，现已加强该路径，但仍需真机复测。

## 安装

安装 `qingyue-pdf-1.13.4.apk`，支持 Android 6.0（API 23）及以上。包名 `cn.qingyue.pdf`，版本代码 22，目标 API 35。正式 APK 须沿用原签名，覆盖安装可保留数据；不要先卸载旧版。更新前建议保存一份 `.qyb`。多页笔记保存为 v3，更新后请继续使用本版或更新版本，旧版不能读取新笔记格式。
