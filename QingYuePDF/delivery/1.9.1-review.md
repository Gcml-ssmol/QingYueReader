# 晴阅 1.9.1 修复审查记录

日期：2026-09-23。基线：已交付的 1.9.0（版本代码 11）。本版为 1.9.1（版本代码 12）。

## 用户反馈与处理

1. 不同工具的颜色共通，需要分别记住设置。
   PDF 与笔记编辑器按工具保存颜色；画笔、荧光笔、直线、矩形、椭圆/圆、箭头的粗细独立；PDF 两种橡皮的范围独立。共享色板可以继续使用，选中的颜色仅更新当前工具。旧共享颜色迁移为画笔颜色；尚无独立设置的荧光笔用黄色。切换先关闭旧工具弹窗，再加载新工具偏好，避免关闭回调污染新工具。

2. PDF 选字只能整行，不能拖动或跨行。
   提取阶段按字形/码点保留文本位置；选择阶段按起止字形在阅读顺序中的范围建立选区，支持顺向与反向跨行。命中先确定最近行，再确定行内字符，行尾空白不会选回上一行。增加可见蓝色端点、固定屏幕触摸范围和抓取偏移，端点在页边也可操作。复制、高亮与来源操作改为原生非模态 ActionMode 工具栏，显示时仍能触摸页面，不再每次松手都用对话框阻挡后续拖动。本次不增加跨页选字。

3. 打开 PDF 导航后，页面刚显示即闪退。
   已修复以下确定存在的代码问题，但没有设备崩溃堆栈，不能断言其中某一项是反馈设备的唯一原因：
   - 导航使用的 Collections.emptySortedSet 仅在 Android API 26 起提供，旧 APK DEX 中未回退，而应用最低支持 API 23。改为兼容的 TreeSet 初始化，新 DEX 已确认不含该调用。
   - 后台解析目录原先仅捕获 IOException，PDFBox 的运行时解析异常可结束应用；现在转换/处理为可恢复错误，显示提示，缩略图与书签仍可使用。
   - 缩略图缓存淘汰与关闭时曾主动 recycle 已交给 ImageView 的位图，界面随后重绘可能异常；现在释放缓存引用，已交付位图交由 GC 在界面释放后回收。
   - 补充空列表、无效页码、书签数量上限和目录节点循环保护。

## 实际验证

- Android 35 API + 实际 PDFBox/POI 依赖完整 Java、资源、DEX 与签名 APK 构建通过。
- 总回归 PASS=26 FAIL=0 SKIP=0：1 个编译检查、11 个基础 Java 测试、14 个脚本套件。
- 工具偏好测试直接使用生产 ToolPreferences，覆盖旧颜色迁移、画笔/荧光笔/几何颜色隔离，以及 PDF 工具尺寸键映射。
- 真实 PDFBox 烟测覆盖文本提取与字形位置，几何测试覆盖跨行/反向范围、长短行尾空白、不同页面宽度下的端点抓取偏移。既有 PDF 导出烟测通过。
- 导航烟测使用真实 PDFBox 验证无目录 PDF、目录目标与自定义页标签、损坏文件、循环目录，均有超时限制。额外损坏页标签样本在真实 PDFBox 中触发 ClassCastException，已确认生产加载器将其转为 IOException（单独补跑通过，见 navigation-final.txt）。
- 缩略图测试直接编译生产 PdfThumbnailProvider：已交付图片总量超过最大缓存后，缓存淘汰和 close 均不让已有引用变成回收位图；打开失败和关闭后的回调也已验证。
- 保留并通过备份恢复、导入、笔记保存/导出、删除事务、阅读状态、缩放等已有回归。
- APK 中导航类存在，调用检查确认 app DEX 已无 Collections.emptySortedSet。
