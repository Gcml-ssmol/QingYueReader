# 晴阅 1.14.0 集成审查

基线为已发布的 1.13.5（code 23）；本轮为 1.14.0（code 24）。用户指定默认无限草稿，保留晴阅特色，并通过适度动画改善界面跳转。各开发任务在独立目录交付，总管核对文件清单、审查跨模块行为后整合。

## 本轮行为

- 创建：首次默认无限草稿；分页笔记保留六种固定纸张尺寸。两种模式均有全空、横线、网格底纹，并记住创建选择。
- 编辑：自由/矩形套索按笔迹、图形、文字、图片筛选；支持多对象拖动、等比缩放、复制、剪切、粘贴、删除、改色和置顶置底。改色保留对象原透明度，图片不改色。
- 工具：最多八支本地常用笔预设；局部与整笔橡皮；明确的只读浏览模式。
- 导航：无限草稿支持最高 1000% 缩放和返回原点；分页笔记保留上下连续浏览与左右翻页，以及插入、调序、复制、清空、删除。
- 过渡：进入笔记约 180 ms，返回约 160 ms；操作面板、侧栏等使用短淡入和小幅移动。重复触发会取消旧过渡并复位，视图移除时复位；系统任一相关动画比例关闭时直接切换。笔迹和持续操作中的画布不添加动画。

## 操作入口

| 操作 | 入口 |
| --- | --- |
| 新建无限草稿或连续纸张 | 资料库 → 新建笔记 → 无限草稿 / 分页笔记 |
| 调整套索及批量编辑 | 工具栏套索；再次点击或长按可选自由 / 矩形；选区操作提供复制、剪切、粘贴、缩放、颜色与前后顺序 |
| 常用笔与橡皮模式 | 笔盒按钮，或笔记设置 → 常用笔盒 / 橡皮设置 |
| 页面前后插入与管理 | 左侧页面栏 → 页面操作，或长按页面缩略图 |
| 无限草稿定位与只读 | 最左侧定位按钮，或右上角操作菜单 → 缩放与定位 / 只读浏览 |

旧版无限笔记如已有多张画布，保留「画布 i/N」及左侧切换入口，导出 PDF 包含全部独立画布。新建无限草稿默认只有一张可延伸的画布；分页笔记才采用连续纸张。

## 数据与操作约定

沿用 v3 笔记格式，不对旧文件做破坏性迁移；v1/v2/v3 读取、来源链接、导出、备份与本地保存继续兼容。对象批量编辑一次操作对应一次撤销。剪贴板仅存在于当前笔记界面实例，退出后不保留，不支持跨笔记图片粘贴。复制页面会给对象分配新标识，图片沿用本笔记内部的有效文件引用。

清空页面可以撤销。删除页面需确认，至少保留一页，删除页面和页面切换不提供跨页撤销。无限画布仍受存储坐标与导出大小的既有边界保护；超出导出范围时报告错误，不承诺无限尺寸的 PNG/PDF。对象置顶置底只调整绘制顺序，不等于独立图层系统。

## 验证范围

发布包旁的 `regression-results.txt`、`provider-results.txt`、`build-results.txt`、`artifact-verification.txt` 是最终实际验证记录。桌面测试使用生产 Java 模型及部分 Android 接口替身；完整构建使用真实 Android SDK。两者均不能替代真机上的手写笔、落掌防误触、长文档帧率、触控手感及动画观感验收。

建议设备验收时顺序检查：新建默认无限草稿；打开与返回、反复开关菜单；关闭系统动画后的直接切换；手掌落屏时书写；套索多个对象后移动、缩放并撤销；分页连续滚动和页间插入；只读模式末页长拖；旧版多画布逐张切换；保存重开及 PDF/PNG 导出。源码测试结果只覆盖交付日志列出的自动检查。

源码按 SHA-256 清单冻结，构建产物与测试输出放在工程外部。打包检查版本、原签名、API 链接、16 KB ZIP 对齐以及源码 ZIP 与目录逐文件一致性；源码包不含私钥或构建缓存。
