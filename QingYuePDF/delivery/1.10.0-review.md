# 晴阅 1.10.0 整合审批

## 交付范围

以 1.9.3 的兼容修复为基础，整合笔记文本框、圆珠笔/铅笔、独立工具设置、50%–300% 缩放控件、目录/书签识别改善及离线 OCR。OCR 可为识别页添加不可见文字层并导出完整 PDF 副本，原文不变。没有加入双栏、录音、复习、多页笔记或同步等延后项目。

参考 APK 仅用于能力比较，未复制其代码或资产。OCR 原生引擎、模型、字体和许可证随源码提供，可离线构建。

## 审查与修正

1. 兼容修复：确认旧包 DEX 调用 `ConcurrentHashMap.keySet():KeySetView` 与打包的兼容库 `keySet():Set` 不匹配。改为 ConcurrentMap 调用后，导航及删除相关三处 DEX 均检查通过；导航读取异常可降级显示，不直接抛出链接异常。
2. 文本笔记：v2 保存文本，兼容读取 v1；文本插入、编辑、移动、四角缩放、删除可撤销重做，使用共享排版绘制到画布及 PDF/PNG。审查修复了纵向缩放不改变字号、字号变化未被当作变更的问题。
3. 文具：圆珠笔、铅笔设置独立。PDF 预览和成稿共用笔迹构造/绘制，限定图形模式为 6–9；修复图形轻点误存自由笔点、越页预览端点与提交不一致。
4. 目录与书签：区分原文目录和用户书签；加载失败有准确空状态。页标签损坏时退回普通页码，保留可读取目录。真实 PDF 测试覆盖命名目标、GoTo 动作与无目标父节点下的嵌套目录。
5. OCR：每批最多 20 页，单页渲染上限 3000 像素边长，取消可停止原生识别；原生链接失败转为可报告错误。识别前后校验实际 PDF 哈希，导出时复制并再次校验原文，避免保存位置选择期间源文件改变。
6. OCR 导出：使用经验证的静态中文/拉丁字体，按字框写入不可见文字，保留原页与旋转/裁剪设置。禁止覆盖源文件；签名或权限受限文档给出失败提示。修订文字仅保存/复制，导出需原识别结果。旋转保存选择器保留待导出快照，进程终止需重做；退到后台取消运行任务。
7. OCR 数据：识别文字进入 .qyb 备份，KEEP_BOTH 恢复改映射文档 ID。永久删除把文字目录纳入原删除事务，支持回滚与恢复；晚到保存不会重建已删除目录。
8. 打包：校验 OCR 原生库、模型、字体散列。四种 ABI 共 16 个原生库以不压缩方式写入 APK，检查 ELF 与 ZIP 16 KB 对齐；真实包资产逐项比对源码/依赖。沿用已有签名，code 15。

## 验证与交付结论

总回归覆盖存储、删除、恢复、文本数据、压感/橡皮、缩放、文字检索、导航和诊断。额外用真实 PDFBox 对最终字体做中文英文抽取、裁剪/旋转坐标、源文件字节不变测试。实际执行日志、APK 散列、签名和源码 ZIP 对照报告见安装包同目录。

通过代码及包级审查后，作为 1.10.0 候选版交付用户安装验收。没有连接 Android 设备，不把 Java 替身测试或成功打包描述为真机验证。仍需验收 OPPO Android 16 导航、小米 Android 13 删除最后一份、实际压感、屏幕布局、OCR 准确率和系统文件选择器。
