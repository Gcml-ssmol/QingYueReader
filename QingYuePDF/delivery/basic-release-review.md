# 1.8.0 基础版审批记录

范围依据：2026-09-23 用户要求停止全量扩展，尽快提交可用基础版。原六个模块任务已停止，代码保留在各工作树；本次未合并其开发中的接口和数据迁移。

本版采用稳定 1.7.0 数据模型，保留导入、PDF 阅读/批注、单页笔记、图片与自动保存，新增外观设置及笔记 PDF/PNG 导出。

| 项目 | 审查结论 |
| --- | --- |
| 外观 | 两个主要 Activity 接入 ThemedActivity；去除静态调色缓存；注册设置入口；浅色纸张与深色界面分离；按钮前景色匹配主题 |
| 笔记导出 | 独立代理实现，总窗口复核。点击时复制文档；后台输出；保存选择器 token；进程被杀时明确要求重试；限制范围和像素；图片不可读时报告失败 |
| 旧数据 | NoteDocument、NoteStore、InkStore 数据格式保持原版；损坏文档列表不再被退出保存覆盖 |
| 构建 | 原依赖与既有签名；SDK 原生工具改用相对路径；保留所有 DEX、字体和许可证 |
| 暂缓功能 | 多页、OCR、双栏、录音、复习、同步、完整备份、回收站、PDF 批注导出 |
| 设备检查 | 用户暂不连接设备；未验证安装、布局、手写、文件选择器和导出实际显示 |

独立只读复核未发现这次小范围改动的高置信阻断问题。总窗口批准进入基础版文件交付；不代表完成原先的全功能计划或通过真机验收。

最终构建与测试结果以随包「验证说明-1.8.0.txt」为准。
