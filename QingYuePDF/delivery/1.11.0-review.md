# 晴阅 1.11.0 整合审批

## 交付范围

本次只整合 EPUB 正文导入、资料库文件夹直接显示、OCR 页面与识别选项改进、摘录到笔记及返回原页。以 1.10.0 为基础，保留既有笔记、局部橡皮、缩放、导出和崩溃兼容修复；不混入同步、录音、复习等其他分支。

三个协作子任务使用 GPT-6 Sol low；主任务复审整合后的代码、执行回归和打包。本版 code 16，沿用原签名。

## 审查与修正

1. EPUB：读取容器、OPF 和 spine 顺序，提取 XHTML 正文，再交给既有 PDF 排版流程。检查 ZIP 路径、条目数量、解压大小、正文长度和取消。修复百分号残缺路径导致循环不前进的问题；中文路径严格 UTF-8 解码。
2. Android XML：去掉不兼容 Android Expat 的 Xerces 专用配置。外部实体解析只返回固定的本地 XHTML 实体，不读取文件或网络；拒绝内部实体声明。测试覆盖正常 DOCTYPE、隐藏在注释后的实体声明和常用 XHTML 实体。
3. EPUB 加密边界：受保护正文拒绝导入；只忽略已在书目声明、采用标准字体混淆标记且不参与本文重排的字体。没有解密正文，也没有移植参考应用的代码或资源。
4. 文件夹：大屏常驻左栏，窄屏横向分类。数量与过滤使用同一资料索引，排除已删除项；整理后刷新侧栏，不依赖重新启动。右侧标题按实际剩余宽度折行，沿用列表快照和缩略图生命周期保护。
5. OCR：默认中文优先，增加中英/英文及正文/封面模式；中文模型改为固定版本的官方 tessdata_best。安装器核对大小和 SHA-256，替换旧模型。模型来源、散列和许可证随源码提供；这是模型选择调整，不是晴阅样本上的准确率评测结论。
6. OCR 界面与预览：明确页码标签，主操作、复制/保存/导出分组，整页滚动，结果区域随内容展开。原页按需渲染，最长边 1600 像素、最多 250 万像素，使用独立队列，关闭/退后台取消；过期未展示位图释放，已交给界面的位图不提前回收。预览失败和内存不足给提示，不使后台线程异常退出。
7. 来源：阅读器改为“摘录到笔记”，支持新建和已有笔记；来源文字与 URI 随文本项保存，可在笔记顶部返回原页。回跳复用 MainActivity，并关闭旧笔记编辑器，避免同一笔记的旧实例覆盖后续编辑。
8. 保存与恢复：插入来源记录 item ID，保存成功才消费请求；失败保留 Intent/状态中的重试线索，重建先找已有条目，防止重复插入。返回原文前保存失败则留在编辑器。新建 A4 前检查长摘录高度，放不下时提示使用无限画布，不提交空笔记。备份 KEEP_BOTH 恢复同时重映射文档和笔记编号时，更新文本项的来源 URI。

- 打包校验检查旧崩溃所涉及的三处 keySet():Set DEX 调用及随包实现，检查 OCR 字体、模型、许可证、四种 ABI 的 16 个原生库及 16 KB 对齐。
- 最终安装包签名、版本、源码目录与 ZIP 逐文件散列结果，以及原始日志，随安装包交付。

## 交付结论与验收边界

通过代码及包级审查，交付 1.11.0 候选版安装验收。没有连接 Android 设备，未验证实际安装、屏幕布局、手写触控、系统文件选择器或原生识别效果；不能把 JVM 替身测试称为真机测试。

EPUB 是正文重排 PDF，并非保留图片/CSS 的原生 EPUB 阅读器。单个 EPUB 最多 64 MB，条目合计解压 48 MB，单条目 8 MB，正文 200 万字符，生成 PDF 最多 400 页。受 DRM 保护的正文不支持。

用户尚不确定 OCR 错误是否也影响正文，且未提供该文件；未用标题或文件名替代识别文字。中文模型升级及封面模式可能改善部分页面，但实际效果须用原文件复测。模型会增加包体与识别耗时；低置信度提示不能代表真实准确率。修订文字仍只能保存/复制，重新导出文字层需未修改的识别结果。

来源链接在本机晴阅中使用，原文需仍在资料库。笔记 PDF/PNG 导出显示来源文字，但不附可点击回跳链接。覆盖安装可保留旧数据，不要先卸载应用；重要资料可先导出 .qyb 备份。
