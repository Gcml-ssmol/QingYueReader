# OCR integration notes (1.10)

- Launch `OcrActivity` with `docId` (library UUID) and `page` (zero based). Register it in the manifest. The activity only accepts an existing, active PDF library item and reads `files/<docId>.pdf`.
- Gradle needs `sourceSets.main.assets.srcDir '../third-party/ocr/models'`, `implementation files('../third-party/ocr/tesseract4android-4.9.0.aar')`, and `implementation files('../third-party/ocr/annotation-1.3.0.jar')`. The checked in model and binary hashes are in `third-party/ocr/SHA256SUMS`.
- The separate PowerShell APK builder must extract the OCR AAR's `classes.jar`, DEX it, package all `jni/<abi>/*.so` entries uncompressed and 16 KB ZIP aligned, and include `assets/tessdata/{chi_sim,eng}.traineddata` plus OCR notices. A Gradle dependency alone does not change that custom builder.
- OCR corrections are atomic files under `files/recognition/<docId>/page-<zeroBased>.txt`. BackupManager includes these files and remaps document IDs on KEEP_BOTH restore. TrashManager stages the whole directory in the existing recoverable deletion transaction; never delete it independently before the transaction commits. OcrSidecar rejects writes for staged, removed, or trashed documents.
- Export uses `ACTION_CREATE_DOCUMENT` and appends invisible text to a new PDF. It uses bundled `assets/ocr/ocr-font.ttf`, a single static Apache-2.0 CJK/Latin TrueType font derived from official AOSP fonts; provenance and regeneration are in `third-party/ocr/FONT-PROVENANCE.md`. It refuses export when corrected text differs from the recognized text, because word coordinates no longer match. The UI accepts a range of up to 20 pages; all original PDF pages remain in the exported copy. Signed PDFs and PDFs forbidding modification or extraction are rejected.
- `tests/recognition/run.ps1` checks hOCR parsing and cancellation. `run-pdf-export.ps1 -FontFile app/src/main/assets/ocr/ocr-font.ttf` creates a real PDFBox PDF, adds invisible Chinese and English text to rotated/cropped pages, and extracts it again; this exact bundled font passed. `check-elf-alignment.ps1` checks arm64 ELF load segments for 16 KB alignment. `verify-apk.py <apk>` checks packaged font/model/license/native-library bytes, native ZIP storage and 16 KB alignment. Device recognition accuracy and runtime UI still require installation testing.
