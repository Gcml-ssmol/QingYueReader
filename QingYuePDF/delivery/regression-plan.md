# 晴阅总回归与验收计划

## 目标与边界

`tests/run-regression.ps1` 是本地、可重复的回归入口。它只编译和运行平台无关 Java 测试及明确允许的测试脚本，不构建 APK、不访问网络，也不改动应用源码。默认产物目录是仓库根目录下的 `work/tests`；每次运行创建独立子目录，保留 class、生成的测试夹具与 PDF 搜索烟测缓存供排查。

当前自动化主要验证模型、解析器和几何/输入策略。它使用桌面 JVM 和测试专用 Android shims，不能代替 Android 真机或模拟器验证。现阶段没有已连接设备，因此下文的设备验收仍是发布前待办。

## 执行方法与判定

在仓库根目录运行：

```powershell
.\QingYuePDF\tests\run-regression.ps1
```

指定产物目录：

```powershell
.\QingYuePDF\tests\run-regression.ps1 -BuildDirectory 'D:\qingyue-regression'
```

脚本逐项输出 `[RUN]`、`[PASS]`、`[FAIL]` 或 `[SKIP]`，末尾给出汇总和本次产物路径。任一编译或测试失败时退出码为 1；全部已执行项通过时退出码为 0。纯 Java 编译失败时，11 个依赖该编译结果的测试标为 `SKIP`，其余独立脚本仍继续执行，以便一次收集尽可能多的故障信息。

测试目录中新增的直接子目录只要包含约定入口 `run.ps1` 就会被发现，但不会自动执行。确认脚本可信且接受 `-BuildDirectory` 后，按目录名显式加入允许列表：

```powershell
.\QingYuePDF\tests\run-regression.ps1 -AdditionalSuiteAllowList 'data-migration','backup-restore'
```

内置允许列表仅包含 `note-store`、`document-import` 和 `pdf-search-smoke`。新增脚本必须完全离线，并把所有临时文件和生成物写入收到的 `BuildDirectory`。

## 发布前优先验收

以下六项是下一阶段的最高优先级。对应功能落地时，应先补可离线运行的 JVM/仪器化自动化，再在至少一台 API 23 低端设备和一台当前主流 Android 设备上完成真机检查。

### 1. 旧数据升级

- 用上一正式版本创建含多份 PDF、跨页批注、普通/无限画布笔记、图片、中文文件名和文件夹层级的数据集，再覆盖安装新版本；不得清除数据。
- 首次启动迁移应成功、可重复且幂等；强制结束后再次启动不得重复条目、丢批注或产生半迁移文件。
- 验证旧批注坐标、颜色、笔宽、笔记纸张/视口、图片引用和最近阅读页一致；损坏或缺失单项应被隔离并给出可操作提示，不得阻断其他数据打开。
- 在存储空间不足和迁移中途杀进程场景验证原数据仍可恢复。迁移测试夹具必须随仓库保存，不能依赖线上旧版本资源。

### 2. 备份与恢复

- 备份包需覆盖文档元数据、PDF、批注、笔记、笔记图片及功能版本信息；在全新安装上恢复后逐项核对数量、内容和关联关系。
- 验证同名/同 ID 冲突策略、重复恢复的幂等性、缺少原 PDF、中文及超长文件名、大文件、空间不足和用户取消。
- 篡改、截断、路径穿越和不支持版本的备份包必须在写入现有数据前被拒绝；失败恢复不得破坏已有资料。
- 完成“备份→卸载/清数据→重装→恢复→再次备份”的闭环，并比较清单与内容摘要。

### 3. 中文 PDF 导出

- 导出含简体/繁体中文、标点、生僻字、拉丁字符、竖横屏页面及透明荧光笔的文档；在系统查看器和至少一个第三方查看器中打开核对。
- 页面尺寸、方向、页数、裁切区域、批注位置、颜色和线宽必须保持一致；放大后笔迹不应明显锯齿或错位。
- 若产品承诺可搜索文本，导出后的中文文字层必须可搜索、复制并保持正确顺序；若仅栅格化，应在界面明确告知。
- 验证中文文件名、已有同名文件、取消、空间不足、长文档和导出期间切后台/杀进程；原文档与内部批注不得被修改。

### 4. 生命周期与任务恢复

- 分别在文档导入、笔记保存、批注保存、备份/恢复、PDF 导出、OCR 和录音进行中执行旋转、分屏、锁屏、Home、系统回收 Activity 和进程重启。
- 界面重建后应重新绑定同一任务并展示真实进度；完成结果只能提交一次，取消必须清理临时文件，旧 Activity 不得删除新 Activity 已接管的结果。
- 验证连续书写后立即返回、切后台和强制结束时的最后一笔；保存失败应显示可恢复状态，后续成功保存后错误状态要消失。
- 仪器化用例至少覆盖 Activity 重建和进程恢复；真机再覆盖系统文件选择器、权限弹窗和低内存回收。

### 5. 离线 OCR

- 开启飞行模式并禁用网络权限后，对纯扫描中文 PDF、相册图片、混合中英文、不同旋转方向和低对比度页面识别；整个流程不得发起网络请求。
- 结果应可搜索并准确跳到来源页；抽取固定离线夹具统计字符准确率和页级召回，阈值在功能实现时冻结并纳入回归。
- 验证语言包首次可用性、取消/重试、部分页失败、超长文档、内存压力、温升及后台恢复；失败不得污染已有文本索引。
- OCR 模型、许可证和测试素材必须本地随附并记录版本，回归不得临时下载。

### 6. 录音

- 验证首次拒绝、稍后授权和永久拒绝麦克风权限；开始、暂停、继续、停止、回放、删除及与当前文档/页/笔记的关联均应一致。
- 覆盖旋转、锁屏、切后台、通知栏控制、来电/音频焦点丢失、蓝牙设备切换、应用被杀和设备重启；可恢复文件不得只有不可播放的尾部。
- 验证无声录音、超长录音、空间不足、文件名冲突和并发打开另一文档；状态栏/前台服务提示须与实际录制状态一致。
- 导出或备份恢复后核对录音时长、可播放性、时间锚点和所属文档；未授权时不得留下空文件。

## 设备回归补充

除上述新增能力外，真机仍需覆盖触笔与手掌拒绝、双指撤销、手机/平板及软键盘布局、多张大图同屏、长笔迹流畅度、数百页 PDF 首屏/翻页、Word 导入取消，以及真实中文 PDF 搜索定位。记录设备型号、Android 版本、输入设备、样本文档摘要、步骤、预期与实际结果，并保存崩溃日志和导出样本。

自动化全绿只能证明本地 JVM 基线未回退。发布签字还需要 APK 构建验证、目标设备上的上述验收以及已知限制复核；本总回归脚本有意不执行 APK 构建。
