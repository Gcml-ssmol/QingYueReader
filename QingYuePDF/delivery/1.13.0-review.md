# 晴阅 1.13.0 整合审核

版本 1.13.0 / versionCode 18，基于已交付 1.12.0，原签名不变。总任务审查整合；两个开发子任务及独立审查使用 GPT-6 Sol low。本轮未新建需要归档的用户任务，前次四个旧任务的归档记录保留在 1.12.0-task-archive.md。

## 通过审核的内容

1. 外观设置改为带主题/纸张预览的卡片选择；首页工具入口移为右下齿轮，不显示文字，具有无障碍说明和边距。
2. NoteDocument 升级至 v3 多页格式，读取已发布的 v1/v2 单页文件，不采用旧分支同版本号异布局的实现。每页内容、视图独立；全笔记对象编号唯一，重复编号在写文件前拒绝。
3. 固定纸张浏览模式增加有阈值、主方向和边缘判断的翻页/末页增页；按用户要求为向下、向右增页。无限画布仍用按钮。页面工作栏可收起，真实内容预览与选页、上移/下移相接。
4. PDF 导出全部页，PNG 当前页。搜索提供方按页输出且指纹含页序；NoteActivity 消费搜索页码并同步资料库页数。返回首页先重新读索引，避免旧快照覆盖新页数。
5. 备份副本恢复逐页重映射来源链接，完成后恢复当前页；NoteStore 原子保存和图片目录整体管理保持有效。

## 审查中修正

- 旧单页 v2 与旧子项目多页 v2 布局冲突：本次使用新 v3 及已发布格式读取器。
- 只搜当前页、只 remap 当前页来源链接、首页旧快照覆盖页数、搜索结果未选择目标页等跨模块遗漏均已补齐。
- 缩略图可见后才按需异步读取图片，小图缓存限 6 MB，避免全笔记原尺寸图片解码；不提前回收仍被绘制的位图。
- 去掉新缩略图代码中的 Float.isFinite，使用 Android API 23 可用的 NaN/Infinity 判断。
- 每页切换或调序会清空撤销栈；避免在另一页回放旧操作。同步索引失败会提示，未把失败写成成功。
